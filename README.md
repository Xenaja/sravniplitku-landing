# Лендинг «СравниПлитку»

Продакшн-вёрстка лендинга по бандлу `design_handoff_sravniplitku_landing/`.
Статическая страница без сборки: открывается на любом хостинге, правится руками.

**Превью для согласования:** https://xenaja.github.io/sravniplitku-landing/

Это черновик на согласование, а не боевой сайт. На превью:

- вместо видео, скриншотов сервиса и работ студии — заглушки с подписью слота;
- контакты и отзывы — заглушки, суммы тарифов предварительные;
- форма проверяет поля по-настоящему, но заявку не отправляет: на GitHub Pages
  нет PHP. Вместо отправки показывается плашка «это превью».

Режим превью включается сам — по домену (`assets/js/config.js` → `preview`).
Ничего переключать перед боевым деплоем не нужно: на своём домене форма
заработает, а страница перестанет закрываться от индексации.

Дизайн-бандл в репозиторий не выкладывается (см. `.gitignore`): в нём разбор
созвона с цитатами клиента, открытые вопросы и фото основателя.

## Структура

```
index.html                  разметка, ни одного инлайн-стиля и скрипта
assets/
  css/
    tokens.css              цвета, шрифты, размеры, радиусы, ритм — все значения дизайна
    base.css                сброс, типографика, контейнеры, фокус, prefers-reduced-motion
    components.css          кнопки, бейджи, сетка-на-подложке, медиа-слоты, текстуры, поля формы
    sections.css            раскладка шестнадцати секций по порядку
    responsive.css          адаптив, подключается последним
  js/
    config.js               ЕДИНСТВЕННОЕ место с настройками: цены, флаги, endpoint, аналитика
    main.js                 точка входа, собирает модули
    modules/
      tile-state.js         общее состояние плитки (демо и шторка показывают одно и то же)
      tiles.js              переключение классов текстур
      demo-scene.js         интерактивная сцена: зоны, коллекции, раскладка
      compare-slider.js     шторка «было / стало», мышь + касание + клавиатура
      segment-tabs.js       переключатель «Салонам / Поставщикам»
      pricing.js            пересчёт цен, скидки и «вместо N ₽»
      lead-form.js          валидация, маска телефона, состояния отправки
      utm.js                сбор и хранение UTM-меток
      analytics.js          цели: demo_click, demo_interact, lead_form_submit, …
      sections.js           включение/выключение секций по флагам
api/
  lead.php                  приём заявки: валидация, лог, письмо на почту
  logs/.htaccess            логи с персданными закрыты от веба
```

Порядок подключения CSS важен: `tokens → base → components → sections → responsive`.
Правило из `responsive.css` должно перебивать `sections.css`, поэтому он последний.

## Запуск локально

Скрипты подключены как ES-модули, а браузер не грузит модули с `file://`.
Двойной клик по `index.html` покажет вёрстку без интерактива — нужен HTTP:

```bash
cd vilrey-lending
python -m http.server 8080
# открыть http://127.0.0.1:8080/
```

Форму целиком (вместе с `api/lead.php`) удобнее проверять на встроенном сервере PHP:

```bash
php -S 127.0.0.1:8080
```

## Что менять при правках клиента

| Что | Где |
| --- | --- |
| Цены тарифов, скидка | `assets/js/config.js` → `pricing` |
| Отключить секцию отзывов | `assets/js/config.js` → `sections.testimonials: false` |
| Адрес приёма заявок | `assets/js/config.js` → `form.endpoint`, плюс `MAIL_TO` в `api/lead.php` |
| Счётчик Метрики | `assets/js/config.js` → `analytics.yandexCounterId` |
| Цвета, шрифты, отступы | `assets/css/tokens.css` |

Проценты и строка «вместо 36 000 ₽» **считаются** из `monthly` и `annual`.
Руками их писать нельзя — разъедутся с ценами.
`trial: 0` печатает «минимальная сумма»; поставьте число — появится сумма.

## Форма

Обязательны: телефон и оба согласия. Четыре поля портрета клиента
(сеть/магазин, точки, чек, кто подписывает счёт) тоже помечены `required` —
клиент просил собирать портрет. Если конверсия просядет, снимается атрибутом
`required` у нужного `<select>`, ничего больше править не нужно.

Телефон нормализуется к `+7XXXXXXXXXX` перед отправкой; в поле у человека
остаётся его запись. Ошибки гаснут, как только он начинает править поле.

`api/lead.php` кладёт заявку в `api/logs/leads.log` и шлёт письмо на `MAIL_TO`.
Персональные данные остаются на сервере клиента — наружу ничего не уходит.
Перед запуском: заполнить `MAIL_TO` / `MAIL_FROM`, проверить права на `api/logs/`
и закрыть каталог от веба (на nginx `.htaccess` не работает, см. комментарий в файле).
Если письмо не ушло, заявка всё равно в логе, а в error_log сервера появится запись.

## Аналитика

`assets/js/modules/analytics.js` шлёт цели в `dataLayer`, `ym` и `gtag` —
что подключено, туда и уйдёт. Цели: `demo_click`, `demo_interact`,
`lead_form_submit`, `trial_request`, `supplier_request`, `segment_switch`.

Новую цель на кнопку вешать разметкой, без правки скриптов:
`data-track="имя_цели" data-track-place="где"`.

## Шрифты

Сейчас Google Fonts, как в макете. Для прода лучше положить локально:
быстрее и не отдаёт IP посетителей стороннему сервису. Меняется одной
строкой `<link>` в `<head>` плюс `@font-face` — семейства уже вынесены
в токены `--font-display` / `--font-body` / `--font-mono`.

## Отличия от бандла дизайна

- Хендофф предлагал перенести макет в React / Next / Astro. Сделано на чистых
  HTML + CSS + JS по требованию заказчика: стили и скрипты лежат отдельными
  файлами, сборка не нужна.
- `support.js` и `image-slot.js` из бандла — рантайм среды прототипирования,
  в продакшн не переносились (так и написано в хендоффе).
- Мобильная версия в макете не проработана. Сделана по точкам внимания из
  раздела «Адаптив»: двухколоночные сетки в одну колонку, шторка растёт
  с 24/9 до 16/9, навигация переезжает на свой этаж в шапке (скролл вбок
  сохранён — ни один пункт не исчезает), добавлена липкая кнопка действия.
- Добавлено то, чего в прототипе нет по определению: семантические теги,
  состояния фокуса, `aria-*` для сцены/шторки/вкладок, управление шторкой
  с клавиатуры, ловушка для ботов, разметка FAQPage для поисковиков.
- Кнопки в тарифах в макете — неинтерактивные плашки; здесь это ссылки на
  форму с пометкой источника (`pricing-trial`, `pricing-monthly`, `pricing-annual`).

Цвета, типографика, отступы, радиусы и копирайт — из макета без изменений.
