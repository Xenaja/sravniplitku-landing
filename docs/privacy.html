2. Какие данные обрабатываются

Оператор обрабатывает только те данные, которые Пользователь сообщает сам, и технические данные, которые передаёт браузер:

  • номер телефона;
  • адрес электронной почты — если Пользователь выбрал этот способ связи;
  • выбранный способ связи (Telegram, WhatsApp, электронная почта);
  • сведения, которые Пользователь указал в форме дополнительно;
  • IP-адрес, дата и время обращения — записываются автоматически при отправке формы;
  • адрес страницы, с которой отправлена заявка, и метки перехода (UTM).

Оператор не обрабатывает специальные и биометрические категории персональных данных и не собирает данные несовершеннолетних осознанно.
